# Deployment
Backend: `composer install --no-dev -o`, set `APP_ENV=production APP_DEBUG=false`, MySQL creds, `php artisan key:generate`, `migrate --force`, then `config:cache route:cache`. **Do not run `migrate:fresh` or the demo seeders in production**; create the first admin by setting `VF_ADMIN_EMAIL`/`VF_ADMIN_PASSWORD` before `db:seed --class=UserSeeder`, then remove them. Serve over HTTPS. Frontend: `npm ci && npm run build`, host `dist/` with SPA fallback to `index.html`, set `VITE_API_BASE_URL` to the API origin and allow that origin via CORS (`config/cors.php`).
