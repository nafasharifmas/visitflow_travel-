# Landing 3D
`src/landing/Scene3D.tsx` (Three.js, lazy chunk). Scene graph: one `sheet` group (GridHelper + 5 contour lines + 5 pin edge-meshes + CatmullRom route + 3 outline cards). Line work only: no lights, textures or shadows. Camera: perspective 38°, driven by scroll progress with easing. Timeline: 0–.25 unfold · .28–.5 pins · .5–.78 route `drawRange` · .76–.96 cards · end settles. Rendering runs only while eased progress ≠ target (no idle rAF). Disabled (static `SceneFallback` SVG) for width < 768, `prefers-reduced-motion`, or no WebGL. Cleanup disposes geometries/materials/renderer. Not visually reviewed in a browser here.
